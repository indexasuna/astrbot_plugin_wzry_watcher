# astrbot_plugin_wzry_watcher 王者荣耀动态订阅

监听王者荣耀官方网站（pvp.qq.com）全频道动态的 AstrBot 插件。官方接口直连，公告原文以速览卡 + 全文长图输出。

## 功能

- **五频道全量监控**：热点 / 新闻 / 公告 / 活动 / 赛事，任一频道有新内容即推送（推送为「标题 + 时间 + 官网链接」的简洁列表）
- **可配置轮询间隔**：后台自动轮询，按公告 ID 跨频道去重
- **公告原文直出**：结构化速览卡（更新时间 / 更新大小 / 本期皮肤 / 官方小节目录）+ 全文长图，官网接口直连、不经 AI 总结
- **关键词过滤**：订阅与查询均支持关键词
- **结构化提取**：速览卡内容由官方正文按规则提取生成

## 指令

| 指令 | 说明 |
|---|---|
| `王者公告 [频道] [关键词]` | 查询最新动态，频道可选：热点/新闻/公告/活动/赛事 |
| `王者公告原文 [序号\|关键词]` | 直出指定公告的速览卡 + 全文长图 |
| `王者订阅` | 查看订阅状态 |
| `王者订阅 on\|off` | 开关定时推送 |
| `王者订阅 群 <群号>` | 设置推送目标群 |

> 别名：`王者动态` `王者更新` `王者活动`；`公告原文` `王者原文` `王者公告全文`

## 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `keywords` | 更新,公告,活动,福利,新皮肤,版本 | 订阅关键词（逗号分隔） |
| `channel` | 公告 | 默认查询频道 |
| `fetch_limit` | 20 | 每次拉取条数 |
| `push_enabled` | false | 启用定时推送 |
| `push_interval_minutes` | 60 | 轮询间隔（分钟） |
| `push_groups` | [] | 推送目标群号列表 |

## 数据来源

列表：`apps.game.qq.com/cmc/cross`（签名算法逆向自官网前端 `newsindex.js`）
正文：`apps.game.qq.com/wmp/v3.1/public/searchNews.php`（官网详情页同源接口）

若某天接口失效，请重新抓取官网前端 JS 检查签名 token 是否更换。

## 字体说明

长图渲染需要中文字体：

- **Windows**：微软雅黑开箱即用
- **Linux**：若系统无中文字体，插件会在首次渲染时自动从 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk) 下载（约 32MB，一次性缓存到插件 `resources/fonts/`）；也可自行安装 `fonts-noto-cjk`
- 完全没有可用字体时优雅回退为文本分片输出

## 数据持久化

- `/AstrBot/data/wzry_watcher.json`：已推送 ID（seen，上限 500）+ 群会话映射

## 安装

从 AstrBot 插件市场搜索「王者荣耀动态订阅」安装，或手动放置到 `data/plugins/` 后重启 AstrBot。
